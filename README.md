# PromptArcade

An arcade of prompt-made classics with a twist — https://promptarcade.games

- 15 games: 13 classics remade by AI with a twist of their own (snake, falling blocks, a brick breaker,
  a road crosser, a maze chase and more) and 2 originals. Each game's `classic` and `twist` live in `src/catalog.mjs`.
- Every game credits the model that made it; every game page links to its full source.
- Global Top 10 boards, Hall of Fame, daily quests, and the Arcade Pass (XP, badges, streaks).

`npm test` · `npm run build` · see [DEPLOY.md](DEPLOY.md).
