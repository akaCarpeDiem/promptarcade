# PromptArcade

Free browser games made entirely by AI from prompts — https://promptarcade.games

- 16 games: a live multiplayer snake arena, a survivors-style roguelite, a merge-physics puzzle, a
  daily word game, a daily roguelike dungeon, a twin-stick shooter, a 3D stacker, and eight classics.
- Every game credits the model that made it; every game page links to its full source.
- Global Top 10 boards, Hall of Fame, daily quests, and the Arcade Pass (XP, badges, streaks).

`npm test` · `npm run build` · see [DEPLOY.md](DEPLOY.md).
